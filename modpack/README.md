# Модпак Zone Raids (Minecraft 1.20.1 Forge)

Extraction shooter в духе Escape from Tarkov и S.T.A.L.K.E.R.: хаб, очередь в рейд, таймер, эвакуация, потеря
снаряжения, схрон, огнестрел, урон по конечностям, военная экипировка, аномалии и артефакты, крюк-кошка, элитры
как редкий лут, голосовой чат на близком расстоянии.

Сборка собирается автоматически в GitHub Actions (workflow **Modpack**) и выдаёт три файла:

| Артефакт | Что внутри |
|---|---|
| `ZoneRaids-client-mrpack` → `ZoneRaids-<версия>.mrpack` | Клиент для Prism Launcher / Modrinth App / ATLauncher |
| `ZoneRaids-server` → `ZoneRaids-<версия>-server.zip` | Готовый сервер: моды, конфиги, скрипты запуска, флаги JVM |
| `modpack-report` | Точный список версий модов (`mods.lock.json`), id предметов, лог тестового запуска сервера |

Скачать: вкладка **Actions** репозитория → последний зелёный запуск **Modpack** → блок **Artifacts** внизу.

Вторая сборка из тех же модов: **Zone Raids: Выживание** (`ZoneRaids-Survival-client-mrpack`, `ZoneRaids-Survival-server`,
`modpack-report-survival` в том же запуске), см. [Вариант «Выживание»](#вариант-выживание).

Зависимости (Architectury, YACL, Konkrete, Melody и т.п.) скрипт подтягивает сам. Точные версии каждой сборки
лежат в `mods.lock.json`.

Сознательно **не** входят в сборку:

* **Lootr**: лут должен лежать только в ящиках Zone Raids, которые перезаполняются раз за рейд. Lootr делает лут
  «один раз навсегда на игрока», это ломает рейды.
* **Grid Inventory**: конфликтует с рюкзаками и Curios (один экран инвентаря).
* **First Aid New**: связка TaCZ + First Aid написана под оригинальный First Aid, два мода с одним modid роняют игру.
* **Миникарта**: в extraction shooter карта местности держится в голове.

## Установка клиента

1. Установите [Prism Launcher](https://prismlauncher.org/) (или Modrinth App).
2. **Добавить экземпляр → Импорт** → выберите `ZoneRaids-<версия>.mrpack`. Лаунчер сам поставит Minecraft 1.20.1,
   Forge и скачает моды.
3. Настройки экземпляра → **Java**: Java 17 (Prism скачает её сам), память **минимум 4096 МБ, максимум 6144 МБ**
   (на ПК с 8 ГБ ОЗУ ставьте максимум 4096, см. «Слабый ПК» ниже). Больше 8 ГБ давать не надо: GC работает дольше.
4. Запустите, зайдите на сервер. Одиночная игра тоже работает (встроенный сервер), но рейды рассчитаны на
   несколько игроков.

## Управление

При первом запуске клиента Zone Raids раскладывает клавиши модов так, чтобы они не пересекались: у модов
по умолчанию на **V** висело пять действий, на **R** перезарядка и перезагрузка шейдеров, на **Shift** присед и
тактический бег. Переносятся только клавиши, которые вы не меняли сами, и только один раз; дальше всё
настраивается в **Настройки → Управление**. Чтобы применить раскладку заново, удалите
`config/zoneraids-keys-5.done` и сбросьте клавиши кнопкой «Сбросить».

Раскладка в духе Tarkov: наклоны на **Q/E** и **Alt + колесо**, высота стойки на **Ctrl + колесо**, инвентарь на **Tab**.

**Бой (TaCZ)**

| Клавиша | Действие |
|---|---|
| **ЛКМ** / **ПКМ** | выстрел / прицеливание |
| **R** | перезарядка |
| **Колесо (нажатие)** | кратность прицела |
| **V** | удар в ближнем бою |
| **G** | режим огня |
| **H** | осмотреть оружие |
| **Z** | обвесы (модификация оружия) |
| **O** | действие с оружием (Interact) |
| **Alt+T** | настройки TaCZ |

**Передвижение**

| Клавиша | Действие |
|---|---|
| **Q / E** | наклон влево / вправо, как в Tarkov: нажал и наклон держится, нажал ещё раз и выпрямился (в `config/zoneraids-client.toml` можно включить режим «пока зажато»). Камера наклоняется и сдвигается вбок, чтобы выглянуть из-за угла; наклон видят другие игроки, хитбокс и точка выстрела на месте |
| **Левый Alt + колесо** | плавный наклон шагами по 10 %, наклон держится; **Q/E** его сбрасывает |
| **Левый Ctrl + колесо** | высота стойки шагами по 10 %: камера опускается плавно, ниже половины включается присед (хитбокс, скорость, поза для других игроков). Бег выпрямляет |
| **C** | перекат, в том числе с места: вперёд или в сторону зажатых WASD (раз в 3 секунды, без неуязвимости) |
| **X** | залечь / встать (Crawl TaCZ) |
| **Ctrl** | бег |
| **Левый Alt** | тактический бег, оружие у груди |
| **Пробел** перед препятствием | перелезть через препятствие в 2 блока (плиты, листва и лёд не подходят) |
| **Shift** | присесть |
| **Caps Lock** | шаг / бег (как в Arma 3; шагом нельзя бежать спринтом) |

Без клавиши, назначьте при желании: High Ready / Low Ready (оружие стволом вверх / вниз), Mantle TACtical
Movement (перелезание уже работает на прыжок), Prone And Slide TACtical Movement (залечь, на бегу подкат) и
Dolphin Dive (прыжок с переходом в залегание).

**Передвижение в духе Arma 3.** Разгон и остановка занимают долю секунды, с тяжёлым грузом дольше. Спринт и
прыжки тратят выносливость (полоска между здоровьем и хотбаром). Быстрее всего она восстанавливается стоя на
месте. На нуле спринт недоступен, а шаг медленнее, пока не вернётся четверть полоски. Груз считается грубо: броня
по её защите, ствол TaCZ 4 кг, патрон 15 г, обвес 0.3 кг, инструменты и оружие 1.5 кг, прочие предметы по 0.1 кг
(содержимое рюкзаков и слотов Curios не считается). К 45 кг скорость падает на четверть, тяжёлый груз
быстрее расходует выносливость. Выносливость Anomaly Zone идёт за нашей, так что она одна.

*Aim Animation* стоит на **ПКМ**, *Animation Reload* на **R**: так другие игроки видят анимации прицеливания и
перезарядки от третьего лица. Красная подсветка конфликта у этих двух клавиш нормальна. Если переназначите
прицеливание или перезарядку TaCZ, перенесите их следом.

**Снаряжение и рейд**

| Клавиша | Действие |
|---|---|
| **Tab** | инвентарь |
| **I** | слоты аксессуаров и артефактов (Curios) |
| **B** | открыть рюкзак (Fracture Point) |
| **U** | снять / поставить бронепластины |
| **N** | ПНВ и спецвидение шлема |
| **Y** | поднять / опустить забрало шлема |
| **L** | ранения по частям тела (First Aid) |
| **J** | режим детектора аномалий |
| **K** | терминал рейдов (карты, очередь, схрон, группа, перки, наблюдение за рейдами) |
| **F** | взаимодействие, как в Arma 3 (см. ниже); предмет во вторую руку теперь в меню **F** без цели |
| **Backspace** | выбросить предмет (с **Ctrl**: всю стопку) |
| **`** (тильда) | список игроков |

**Взаимодействие (как в Arma 3)**

Наведите прицел на дверь, люк, калитку, рычаг, ящик, схрон, прилавок торговца, терминал, питбайк или
другого игрока: под прицелом появится действие по умолчанию, например «[F] Открыть дверь». Работает с любым
предметом в руке, в том числе с оружием TaCZ, у которого ПКМ занята прицеливанием.

| Клавиша | Действие |
|---|---|
| **F** | выполнить действие под прицелом или выбранное в списке |
| **Колесо мыши** (глядя на объект) | открыть список всех действий справа от прицела и листать его; первый поворот только открывает список |
| **F** без цели | меню себя: осмотреть себя, снаряжение и артефакты, карта, КПК, предмет во вторую руку, слезть с байка |

Действия: двери, люки и калитки открыть / закрыть; ящики обыскать; схрон, торговец, терминал, сундуки и бочки
открыть; питбайк: сесть за руль или пассажиром, осмотреть (состояние в %); игрок: осмотреть (цел / ранен /
тяжело ранен), пригласить в группу или принять его приглашение, передать предмет из руки. Список закрывается
через 5 секунд без прокрутки или когда прицел уходит с объекта. **Alt + колесо** и **Ctrl + колесо** по-прежнему
наклон и стойка. Если колесо нужно для смены слота всегда, в `config/zoneraids-client.toml` поставьте
`scrollOpensMenu = false`: тогда первое нажатие **F** открывает список, колесо листает открытый список, второе
нажатие **F** выполняет.

**Связь и графика**

| Клавиша | Действие |
|---|---|
| **Caps Lock** | говорить (Simple Voice Chat) |
| **M** | выключить микрофон |
| **P** | меню голосового чата: громкость, группы, отключить чат |
| **F7** | включить / выключить шейдеры |
| **F8** | выбор шейдерпака и его настройки |

Камеру Camera Overhaul можно ослабить или выключить в её настройках (кнопка в списке модов), если укачивает.

## Слабый ПК (8 ГБ ОЗУ)

Отдельный сервер нужен, только если к вам будут подключаться друзья. Играть одному или проверить сборку проще в
**одиночной игре**: сервер тогда встроен в клиент, и Java работает в одном процессе, а не в двух.

* Prism → Изменить экземпляр → Настройки → Java: память **минимум 2048, максимум 4096 МБ**.
* В игре: дальность прорисовки 6-8 чанков, симуляция 5, графика «Быстро», облака выкл., сглаживание выкл.
* Сервер и клиент на одном ПК с 8 ГБ: серверу 3 ГБ (скрипт ставит сам), клиенту 3-3.5 ГБ, браузер закрыть.

## Шейдеры

В сборке Oculus и шейдерпак **MakeUp Ultra Fast**, он сделан для слабых видеокарт. Шейдеры включены сразу и
настроены под Зону и под карту уровня GTX 650 Ti 1 ГБ:

* **Вид**: свой цветовой профиль пака: серо-зелёное пасмурное небо, блёклый закат, тёмные ночи и подвалы
  (лаборатория без фонаря почти чёрная), мутная вода, туман на максимуме, зелёный ПНВ.
* **Выключено ради FPS**: тени, AO, отражения и преломления, объёмные облака, bloom, глубина резкости, размытие.
  Оставлены дешёвые лучи сквозь туман (Godrays: Depth based) и колыхание травы и листвы.

| Клавиша | Что делает |
|---|---|
| **F7** | включить / выключить шейдеры (если FPS упал в бою, первое, что стоит сделать) |
| **F8** | выбор шейдерпака и его настройки |

Клавиши Oculus по умолчанию (R, K, O) совпадают с перезарядкой, терминалом рейдов и оружием TaCZ, поэтому
они перенесены на F7 и F8, перезагрузка шейдеров без клавиши (см. «Управление» выше).

* С шейдерами держите дальность прорисовки 6 чанков: туман всё равно скрывает дальше.
* Если FPS всё равно мало: **F8** → настройки пака → Godrays: Disabled, Waving: off. Не помогло: **F7**, без шейдеров
  остаётся туман биома Кордона.
* При обновлении сборки лаунчер заново кладёт `config/oculus.properties` (шейдеры снова включатся). Свои настройки
  пака лежат в `shaderpacks/<пак>.zip.txt`, перед обновлением их стоит сохранить.
* Настройки пака по умолчанию: `pack.json` → `shaderpacks[].settings`. Все опции пака и проверка этих настроек:
  артефакт `modpack-report` → `report/shader-options.txt`.

## Установка сервера

Нужна Java 17 (Temurin 17): https://adoptium.net/temurin/releases/?version=17 , в установщике отметьте
«Set JAVA_HOME» и «Add to PATH». Без Java 17 скрипт напишет, где её взять, и не закроется.

1. Распакуйте архив в обычную папку (не запускайте из окна архива), например `C:\ZoneRaids-server`.
2. Windows: запустите **`start-windows.bat`**. Linux: `./start-linux.sh`.
3. Первый запуск скачает и установит Forge, затем спросит согласие с [EULA Minecraft](https://aka.ms/MinecraftEULA)
   (введите `Y`). Дальше сервер стартует; остановка: команда `stop` в его окне.

Память серверу скрипт подбирает сам по объёму ОЗУ: до 12 ГБ → 3 ГБ, от 12 ГБ → 4 ГБ, от 16 ГБ → 6 ГБ.
Своё значение: `set HEAP=5G` перед запуском (Windows) или `HEAP=5G ./start-linux.sh`.
`AUTO_RESTART=1 ./start-linux.sh` перезапускает сервер после падения или `/stop`.

Порты: **25565/TCP** (игра) и **24454/UDP** (голосовой чат). Если голос не работает, почти всегда закрыт UDP-порт.

Что уже настроено:

* `server.properties`: PvP включён, `allow-flight=true` (иначе крюк и элитры кикают за «полёт»), `spawn-protection=0`,
  дальность прорисовки 8 и симуляции 6 чанков, Нижний мир выключен.
* `zoneraids_jvm_args.txt`: G1 с флагами Aikar, дамп кучи при нехватке памяти. Размер кучи задаёт скрипт запуска.
* `defaultconfigs/zoneraids-server.toml`: правила рейдов (отсчёт, эвакуация 10 с, защита при спавне, запрещённые
  в рейде команды), синхронизация игроков, NPC и пуль каждый тик (`[network]`). Применяется при создании мира,
  дальше правится `world/serverconfig/zoneraids-server.toml`.
* `config/voicechat/voicechat-server.properties`: голос слышен на 40 блоков, шёпот и присед тише.

Карта «Кордон» и бункер-хаб строятся модом Zone Raids автоматически при первом старте мира (тред карты), ручная
настройка не нужна. Свои карты добавляются командами `/raidadmin`, см. README мода в корне репозитория.

## Производительность и утечки памяти

Полностью исключить утечки не может ни один мод, поэтому сборка их предотвращает и даёт инструменты, чтобы ловить:

* ModernFix, FerriteCore и AllTheLeaks закрывают известные утечки и снижают расход памяти; Embeddium,
  EntityCulling, ImmediatelyFast поднимают FPS.
* Рейды идут на фиксированных картах, а не на бесконечной генерации, предметы на карте чистятся после рейда.
* Мод Zone Raids хранит только UUID игроков, состояние очищается при выходе, смерти и конце рейда.
* Проверка на сервере: `/spark health --memory` (память и TPS), `/spark heapsummary` (что занимает кучу),
  `/spark profiler start` … `/spark profiler stop` (кто ест тики). Тест на утечку: сыграть 15-20 рейдов подряд и
  сравнить `heapsummary` до и после; после сборки мусора память не должна расти.
* Каждый пуш в репозиторий запускает тестовый старт сервера со всеми модами (`modpack/tools/smoke_test.sh`):
  проверяет, что все моды загрузились, хаб и Кордон построились, каждый предмет из таблиц лута существует,
  ящики выдают оружие TaCZ и медицину First Aid, и печатает отчёт по памяти. На последнем прогоне куча сервера
  после старта и постройки карты занимала около 700 МБ из 4 ГБ.

* Там же `modpack/tools/check_mod_links.py` сверяет байткод аддонов с модами, в которые они вызывают (TaCZ,
  PlayerAnimator и т.д.): если аддон собран под старую версию и ссылается на удалённый класс или метод, сборка
  падает. Так ловятся вылеты клиента, до которых серверный тест не доходит. Отчёт: `report/mod-links.txt`,
  клавиши и mixin-конфиги модов передвижения: `report/movement-mods.txt`, клавиши всех модов по умолчанию и
  совпадения между ними: `report/key-defaults.txt` (по нему составлена раскладка в `KeyLayout.java`).

## Вариант «Выживание»

Те же моды, клавиши, КПК, передвижение, оружие, броня, артефакты и мутанты, но без рейдов: открытый мир, прогресс
не сбрасывается. Плюс два мода с боссами в своих структурах (только в этой сборке):

| Мод | Боссы и где их искать |
|---|---|
| L_Ender's Cataclysm (+ Lionfish API) | Игнис (Горящая арена, Нижний мир), Незеритовое чудовище (Кузня душ, Нижний мир), Страж Края (Разрушенная цитадель, Энд), Вестник (Древняя фабрика), Левиафан (Затонувший город), Маледиктус (Ледяная тюрьма), Древний остаток (Проклятая пирамида), Сцилла (Акрополь) |
| Mowzie's Mobs | Железный Ротнаут (подземный зал), Морозная пасть (снежные биомы), Умвути (деревня в саванне), Скульптор (гора) |

Боссы рассчитаны на хорошее снаряжение: броню Fracture Point, медицину First Aid, автоматы и патроны. С боссов
падают их оружие, броня и материалы для крафта. Ставится так же, как основная сборка (`ZoneRaids-Survival-<версия>.mrpack` и
`ZoneRaids-Survival-<версия>-server.zip`). Одиночная игра тоже работает: новый мир сам получает настройки выживания
из `defaultconfigs`. Мир основной сборки в выживание не превращается: для этого в
`world/serverconfig/zoneraids-server.toml` нужно поставить `enabled = true` в `[survival]`.

* Мир: обычная генерация с биомами Anomaly Zone (Рыжий лес, пси-, термо- и биозоны), где аномалии и артефакты.
  Нижний мир включён. Хаб и Кордон не строятся.
* Враги: рядом с игроком бродят слепые псы, плоти, бандиты и военные с оружием TaCZ; ночью и в биомах Зоны их больше,
  снорки и кровососы появляются ночью и в Зоне. Возле точки спавна мира (64 блока) врагов нет. С врагов падает их лут,
  снаряжение военных и бандитов падает чаще, чем в рейдах (30 %).
* Старт: хлеб, факелы, бинты, контейнер для артефактов КСМ, пистолет и броня из набора раунда. Один раз на игрока.
* Деньги: артефакты и ценности (железо, золото, изумруды, алмазы) продаются торговцу во вкладке КПК, там же оружие,
  патроны, броня, медицина, контейнеры и питбайк. Стволы и патроны можно и собирать на верстаке TaCZ.
* Перки: очко за каждые 10 убитых врагов.
* Смерть по правилам Minecraft: вещи выпадают на месте смерти. Схрон и наблюдение за рейдами выключены.

Настройки: `defaultconfigs/zoneraids-server.toml` из `modpack/variants/survival/` (секция `[survival]`, описание в
[README мода](../README.md#режим-выживания)), `server.properties` там же. Остальные файлы берутся из основной сборки.

## Как менять сборку

* Моды только для выживания: `mods` в `modpack/variants/survival/variant.json`, формат как в `pack.json`.
* Список модов: `modpack/pack.json` (slug с Modrinth, сторона `both`/`client`/`server`, при желании точная версия).
* Таблицы лута ящиков: `modpack/glue/data/zoneraids/loot_tables/crates/{common,military,medical,weapons}.json`,
  набор на начало раунда: `kits/round_start.json`. Список
  настоящих id предметов из модов сборки: артефакт `modpack-report` → `report/registered-items.txt`
  (`item-ids.txt` собран по моделям и содержит id, которых в игре нет). Неверный id роняет всю таблицу, тест это ловит.
* Общие конфиги: `modpack/overrides/`, только сервер: `modpack/server-overrides/`. Вариант «Выживание»:
  `modpack/variants/survival/` (`variant.json` и те же папки, их файлы заменяют файлы основной сборки), собирается
  `build_pack.py ... --variant survival`, тест: `smoke_test.sh <server> <report> survival`.
* Локальная сборка (нужен интернет до Modrinth и Forge):

  ```bash
  ./gradlew build
  python3 modpack/tools/build_pack.py --zoneraids-jar build/libs/zoneraids-0.1.0.jar --out build/modpack
  bash modpack/tools/smoke_test.sh build/modpack/server build/modpack/report
  ```

## Лицензии

Моды скачиваются с Modrinth по ссылкам из `.mrpack` и не перепаковываются, кроме AllTheLeaks (есть только на
CurseForge, кладётся в архив целиком). Перед публичной публикацией сборки на Modrinth/CurseForge проверьте
лицензии в `mods.lock.json` (поле `license`) и замените AllTheLeaks на загрузку через CurseForge.
